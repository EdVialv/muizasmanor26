# MVP scope

## Product objective

Help residents, tourists and event organisers discover Latvian manor estates, understand what each location offers and contact the manor without searching across fragmented websites.

## Primary users

1. Visitors planning cultural trips.
2. Event organisers seeking a suitable venue.
3. Manor representatives maintaining listing information.
4. The platform administrator reviewing content and enquiries.

## Included in the MVP

- Responsive Latvian-first public website.
- Manor directory with pagination.
- Search by manor name and location.
- Filters for region, public access, accommodation, food service and event availability.
- Map markers linked to manor pages.
- Manor detail pages with verified facts, images, location, services, contacts and source/update metadata.
- Admin authentication and role-based access.
- Create, edit, publish and archive manor records.
- Event-enquiry form, consent record, spam protection and email notification.
- Basic SEO, accessibility, analytics, error monitoring and backups.

## Explicit non-goals before validation

- Online payments or deposits.
- Real-time availability and bookings.
- Paid subscriptions or premium placement.
- Multi-stop route optimisation.
- Restoration-service marketplace.
- Funding-application assistance.
- Native mobile applications.
- User reviews and public accounts.

## Validation target

The MVP is validated when, over a defined test period:

- users can find a relevant manor without assistance;
- manor representatives confirm that listing updates are manageable;
- genuine event enquiries are delivered reliably;
- analytics show repeat use or meaningful search-to-enquiry conversion;
- at least five manor operators agree to test a future commercial service.

## Public-launch minimum

- Published records are accurate and traceable to a source.
- Search, filters, map and detail pages work on mobile and desktop.
- Admin access is protected and ordinary users cannot edit content.
- Enquiries reach the intended recipient and are logged.
- Privacy notice, cookie handling where required and consent text are present.
- Error monitoring, analytics and database backups are enabled.
- Accessibility and SEO smoke checks pass.
